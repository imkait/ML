🧠 什麼是 SVM？

支援向量機是一種試圖找到「最寬街道」(最大邊距) 來區分不同類別資料的演算法。

決定邊界位置的訓練點稱為「支持向量」；在軟邊界模型中，也可能位於邊界內或被錯分。

🔮 核函數技巧 (Kernel Trick)

當資料無法用直線分開時，SVM 可以透過核函數將資料投射到更高維度的空間 —— 就像在一張平面地圖上加入「高度」資訊，讓原本混在一起的點在新的維度中可以被一個平面分開。

RBF Kernel 能產生彈性的非線性決策邊界，可以包圍任意形狀的資料群集，不僅限於圓形。

🎚️ C 值的影響

  • C 很大：對錯誤分類容忍度低，通常會較重視分類錯誤，可能形成較窄的邊距；有限大的 C 仍屬軟邊界。
  • C 很小：容許一些錯誤，更容許邊界違規，通常形成較寬的邊距，但也可能欠擬合。
