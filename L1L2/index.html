🛡️ 正規化 (Regularization)

馴服狂野的模型：L1 (Lasso) vs. L2 (Ridge)

⚖️ 特徵權重（不含截距的懲罰）

開始訓練後可觀察權重變化。

多項式特徵未標準化；請比較同一特徵在不同方法下的權重，勿直接用長條高度判斷各特徵的重要性。

🛠️ 模型設定

1 階是線性模型；6 階適合觀察正規化；8 階可探索較複雜的曲線。階數 d 會使用 x、x²、…、xd 共 d 個特徵。

🛡️ 正規化設定

目前未啟用正規化，模型將盡力擬合所有噪聲。

切換 None、L1、L2 會從相同的零權重重新訓練；資料點保持不變，方便比較。

🚀 訓練控制 (梯度下降)

MSE Loss 0.00
Epochs 0

畫面顯示的是訓練資料的 MSE；實際訓練目標另加上 λ × 懲罰值。

🔍 什麼是正規化？

正規化是在訓練目標中加入「懲罰項 (Penalty)」，限制權重大小，降低過擬合的風險。

訓練目標 = MSE + λ × Penalty

此示範只懲罰特徵權重 w1、w2…，不懲罰截距 w0（Bias）。

💎 L1 Regularization (Lasso)

懲罰權重的絕對值總和。

Penalty = ∑i=1d |wi|
  • 特點：傾向產生稀疏解 (Sparse Solution)。
  • 效果：可讓部分特徵權重恰好變成 0，相當於自動排除這些特徵。
  • 幾何意義：解空間是菱形，容易在座標軸上相切。
  • 使用時機：希望模型自動挑選重要特徵 (Model Selection)，或希望模型解更稀疏 (Interpretability) 時。

🔵 L2 Regularization (Ridge)

懲罰權重的平方總和。

Penalty = ∑i=1d wi2
  • 特點：傾向產生小數值權重。
  • 效果：通常讓權重一起縮小，減少模型對單一特徵的過度依賴；一般不會像 L1 那樣產生大量恰好為 0 的權重。
  • 幾何意義：解空間是圓形。
  • 使用時機：特徵之間可能互相關聯 (共線性)，或希望保留所有特徵但減少過擬合時。

💡 觀察重點

  1. 先用預設的 6 階和 15 筆資料比較；再將階數調到 1 或 8，觀察特徵數增加時權重與曲線如何改變。
  2. 先選 None 並訓練，記下權重圖。曲線是否震盪會受資料、階數和訓練時間影響。
  3. 切換 L2 後重新訓練，觀察多個權重是否一起縮小。
  4. 切換 L1 後重新訓練，觀察有多少特徵權重恰好為 0。可調高 λ 讓差異更明顯。
